# Módulos opcionales

Un módulo agrega listas, recetas y chequeos para un uso concreto. Se activan con el asistente (`ruby tools/kos_init.rb`) o a mano con `ruby tools/kos_init.rb --solo-modulo <nombre>`.

| Módulo | Qué agrega |
|---|---|
| `listas` | Películas, series y libros en `knowledge/lists/`, con recetas para que una IA los cargue sin duplicar ni pisar puntajes. |
| `finanzas` | Proyecto `projects/finanzas/` con gastos en CSV, categorías y chequeos de formato. |

Crear tu propio módulo: ver `docs/manual/09-personalizar.md`.
