# Templates

Copy the template, replace what is between `<...>` and delete what you don't use.

| Template | For |
|---|---|
| `project.md`, `manifest.yaml`, `tasks.md` | New project in `projects/<id>/` |
| `decision.md` | New decision in `decisions/` |
| `inbox.md` | Idea or capture in `knowledge/inbox/` |
| `area.md` | Knowledge area in `knowledge/areas/` |
