# Registro

`projects.yaml` es el registro maestro de proyectos. Cada proyecto de `projects/` tiene que estar aquí, con el mismo estado que en `projects/index.md` y en su `project.md` (DEC-002).

Valores de `lifecycle`: `active`, `paused`, `finished`, `archived`.

`zonas.yaml` define lo **crítico**: las rutas y acciones que solo cambian con tu aprobación explícita (por email, con código y PIN). Es en sí mismo crítico. Guía: `docs/manual/13-proteccion.md`.
