# Conectar KOS a Claude.ai (Proyectos)

Claude.ai no ve tu disco. Hay dos formas de darle KOS:

## Opción A — Proyecto con archivos (sin GitHub)
1. En claude.ai crea un Proyecto llamado "KOS".
2. En **Instrucciones del proyecto** pega el texto de `adapters/pegar-en-una-ia.md` (desde la línea horizontal).
3. En **Conocimiento del proyecto** sube: `AGENTS.md`, `ONBOARDING/README.md`, `ONBOARDING/RECETAS.md`, `projects/index.md`, `knowledge/profile.md` y la carpeta del proyecto con el que vayas a trabajar.
4. Cuando Claude te dé un bloque "Para registrar en KOS", pégalo en el archivo indicado (o pídeselo a una IA con acceso a archivos, como Claude Code).
5. Cada tanto, vuelve a subir los archivos que cambiaron.

## Opción B — Conector de GitHub
Si tu KOS está en un repo de GitHub, conecta GitHub en claude.ai y agrega el repo al Proyecto. Claude podrá leer los archivos actualizados; para escribir seguirá entregando bloques "Para registrar en KOS".

## Importante
Desactiva o ignora la memoria de Claude.ai para temas de KOS: la fuente es KOS.
