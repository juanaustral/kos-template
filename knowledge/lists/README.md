# Listas

Tablas Markdown con columnas fijas. Reglas para cualquier IA:
- Agrega filas al final; respeta las columnas.
- No borres filas ni cambies notas, puntajes o estados que ya existen. El validador falla si se pierden filas.
- Busca antes de agregar para no duplicar.

| Lista | Archivo |
|---|---|
| Notas sueltas | `notes.md` |
| Recordatorios | `reminders.md` |
| Herramientas y software | `software.md` |

Los módulos opcionales (por ejemplo, películas, series y libros) agregan sus listas aquí.
