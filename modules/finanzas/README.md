# Módulo: finanzas

Crea el proyecto `projects/finanzas/` con:
- `data/categorias.csv` — categorías de gasto (`id,nombre,tipo`).
- `data/gastos.csv` — un gasto por fila (`fecha,categoria,monto,moneda,nota`), ordenado por fecha.

El validador controla cabeceras, categorías conocidas, montos numéricos, fechas ISO y orden. Los datos son Confidenciales: nunca números de tarjeta, cuenta ni documentos.
