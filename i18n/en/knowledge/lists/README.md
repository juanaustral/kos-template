# Lists

Markdown tables with fixed columns. Rules for any AI:
- Add rows at the end; respect the columns.
- Don't delete rows or change existing notes, ratings or statuses. The validator fails if rows are lost.
- Search before adding to avoid duplicates.

| List | File |
|---|---|
| Loose notes | `notes.md` |
| Reminders | `reminders.md` |
| Tools and software | `software.md` |

Optional modules (e.g. movies, series and books) add their lists here.
