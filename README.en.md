# KOS — English

This template ships in Spanish and English. To install it in English run:

```
ruby tools/kos_init.rb --lang en
```

The wizard replaces every file with its English version (`i18n/en/`), including the manual. Read [`i18n/en/README.md`](i18n/en/README.md) and the quickstart at [`i18n/en/docs/manual/quickstart.md`](i18n/en/docs/manual/quickstart.md) before installing.
