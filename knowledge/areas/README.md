# Áreas

Un archivo por dominio de tu vida o tu trabajo (por ejemplo `trabajo.md`, `finanzas.md`, `salud.md`, `aprendizaje.md`). El asistente `tools/kos_init.rb` crea las que le indiques a partir de `templates/area.md`.

Cada área separa: reglas estables, datos vigentes, datos históricos y pendiente de confirmar.
