# Moldes

Copia el molde, reemplaza lo que está entre `<...>` y borra lo que no uses.

| Molde | Para |
|---|---|
| `project.md`, `manifest.yaml`, `tareas.md` | Proyecto nuevo en `projects/<id>/` |
| `decision.md` | Decisión nueva en `decisions/` |
| `inbox.md` | Idea o captura en `knowledge/inbox/` |
| `area.md` | Área de conocimiento en `knowledge/areas/` |
